Built on a ledger that never forgets

PAYFLOW treats the journal as the single source of truth. Entries are append-only: corrections are new, balanced reversal or refund entries that reference the original transaction.

Security at the core

Identity and access are enforced on the server for every request — not just hidden in the interface.

⛨

Protected accounts

Passwords are hashed with Argon2id. Optional TOTP multi-factor authentication adds a second step, with single-use recovery codes.

◷

Session control

Sessions are stored server-side as token digests, expire automatically, and can be reviewed and revoked from the Security Centre.

▦

Role-based access

Customers, merchants, operators, auditors and administrators see only the capabilities their role permits.
